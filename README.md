# 🎱 BINGO สำหรับงานอีเวนต์

เว็บบิงโกแบบ realtime สำหรับผู้เล่นประมาณ 200 คน
ใช้ Next.js + TypeScript + Tailwind, SSE (realtime), SQLite + Drizzle

## หน้าต่างๆ

| URL | ใช้ทำอะไร |
|---|---|
| `/join` | ผู้เล่นสแกน QR แล้วใส่ชื่อ |
| `/play` | การ์ดของผู้เล่น: แตะเพื่อมาร์ก และกด BINGO! |
| `/host` | หน้าผู้จัด (ต้องใส่ PIN): ตั้งค่ารอบ, สุ่มเลข (กด Space/Enter ได้), จบรอบ |
| `/screen` | จอโปรเจกเตอร์: ลูกบอลใหญ่ กระดานเลข ผู้ชนะ QR (กด "เปิดเสียง + เต็มจอ" 1 ครั้ง) ถ้าเบราว์เซอร์นี้ล็อกอิน host แล้ว (ผ่าน `/host` หรือปุ่ม 🎛️ host) จะมีปุ่ม "สุ่มเลข" และกด Space/Enter สุ่มได้ แม้อยู่ในโหมดเต็มจอ |

## กติกา
- Host เลือกขนาดการ์ด 5×5, 6×6 หรือ 7×7 แต่ละคอลัมน์มี 3N เลข เช่น 5×5 ใช้เลข 1–75
- การ์ดสุ่มเลขแยกตามช่วงของแต่ละคอลัมน์ (5×5 คือ B=1–15, I=16–30 …) และลำดับบนลงล่างก็สุ่มด้วย
- ช่องฟรีตรงกลางเปิด/ปิดได้ (มีได้เฉพาะขนาดเลขคี่)
- ชนะเมื่อครบ 1 เส้น: แนวนอน แนวตั้ง หรือทแยง
- Host กำหนดจำนวนผู้ชนะต่อรอบ ใครกด BINGO ก่อนได้ก่อน ครบจำนวนแล้วรอบจะจบเอง
- เซิร์ฟเวอร์ตรวจผลจากเลขที่สุ่มออกจริงเสมอ การโกงด้วยการมาร์กมั่วจึงไม่ได้ผล
- เลขจะถูกสุ่มตอนแอนิเมชันหมุนจบ (4 วินาที) จึงไม่มีใครแอบดูเลขล่วงหน้าได้

## รันบนเครื่อง

```bash
npm install
cp .env.example .env.local   # แล้วแก้ HOST_PIN
npm run dev
```

เปิด http://localhost:3000/host (PIN เริ่มต้น `1234`)

ถ้าจะทดสอบด้วยมือถือในวง Wi-Fi เดียวกัน ให้เปิด `/screen` ผ่าน IP ของเครื่อง เช่น `http://192.168.1.10:3000/screen`
QR จะใช้ที่อยู่นั้นให้เอง

## Deploy ขึ้น Railway

1. Push โปรเจกต์ขึ้น GitHub
2. ที่ [railway.com](https://railway.com) กด **New Project → Deploy from GitHub repo** แล้วเลือก repo นี้
3. ที่ service ไปที่ **Settings → Volumes → Add Volume** แล้วตั้ง mount path เป็น `/data`
4. ที่ **Variables** ใส่ค่า:
   - `HOST_PIN` = PIN ที่จะใช้จริง (อย่าใช้ 1234)
   - `DATABASE_PATH` = `/data/bingo.db`
5. ที่ **Settings → Networking → Generate Domain** จะได้ URL เช่น `xxx.up.railway.app`
6. ⚠️ ต้องให้ **Replicas = 1** เสมอ (ค่าเริ่มต้นเป็น 1 อยู่แล้ว) เพราะ realtime อยู่ในเซิร์ฟเวอร์ตัวเดียว

Railway จะรัน `npm run build` และ `npm start` ให้เอง

## Checklist ก่อนวันงาน
- [ ] เปลี่ยน `HOST_PIN` แล้ว
- [ ] ลองเล่นจริงด้วยมือถือ 3–5 เครื่องผ่าน 4G และ Wi-Fi ของสถานที่
- [ ] เปิด `/screen` บนเครื่องที่ต่อโปรเจกเตอร์ แล้วกด "เปิดเสียง + เต็มจอ"
- [ ] เปิด `/host` บนอีกเครื่องหนึ่ง (โน้ตบุ๊กหรือแท็บเล็ต)
- [ ] เลือกขนาดการ์ด: ยิ่งใหญ่ยิ่งต้องสุ่มหลายเลขกว่าจะมีคนชนะ (5×5 ไวสุด 7×7 นานสุด)

## โครงสร้างโค้ด
```
src/lib/bingo.ts          กติกา: สร้างการ์ด ตรวจเส้น (ใช้ทั้ง server และ client)
src/lib/server/game.ts    logic ของเกม: รอบ สุ่มเลข ตรวจ BINGO
src/lib/server/bus.ts     ระบบกระจายข้อมูลไปยังทุก SSE connection
src/lib/server/db.ts      SQLite + Drizzle (สร้างตารางให้เองตอนเริ่ม)
src/app/api/events        SSE stream
src/hooks/useGameState.ts รับ state แบบ realtime (ถ้าหลุดจะ fallback เป็น polling)
src/components/NumberRoller.tsx  แอนิเมชันลูกบอลหมุน
```
